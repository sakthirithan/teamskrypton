# Teams Krypton – Leadership Guide

This document explains **leadership responsibilities and controls**.

---

## 👑 Leadership Roles
- Team Captain (TL)
- Vice Captain (VC)
- Strategist
- Team Manager

Each role has **strict authority boundaries**.

---

## 🏠 Home Dashboard
- Today’s Task is always at the top
- Working Panel shows who is active

Home is for **execution visibility only**.

---

## 👤 My Space (Leadership Dashboard)
Your My Space contains:
- same as all members
- Execution insights (role-based)

---

## 🧑‍💼 User Management (TL & VC Only)
You can:
- Approve / Reject new users
- Reset user passwords
- Delete users (governed flow)

---

## ✅ Registration Approvals
- New users appear under **Pending Approvals**
- Only TL & VC can approve or reject
- Users cannot log in before approval

---

## 🗑️ User Deletion
Modes:
1. Request deletion (user accepts/declines)
2. Leadership escalation vote
3. Immediate delete (special permission)

Deletion is **hard & permanent**.

---

## ⚠️ Task Control
Leadership can:
- Create & edit tasks
- Send alerts
- Monitor working users

You cannot:
- Edit timestamps
- Fake completion

---

## 📊 Logs & Exports
- Download global logs
- Download individual logs
- Filter by date range
- Exports include GitHub/doc links

---

## 🔔 Real-Time Updates
All actions sync instantly.
No page reload required.

---

## 🧠 Leadership Responsibility
- Use data, not pressure
- Correct behavior through system rules
- Maintain fairness and clarity

This system enforces discipline — **use it wisely**.
